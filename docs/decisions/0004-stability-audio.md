# 0004 — Stability AI audio and sung-vocal requirement

Superseded for final songs by [decision 0005](0005-elevenlabs-final-songs.md). The Stability instrumental adapter remains available.

Status: selected for Phase 03 instrumental generation. Date: 2026-11-11. This supersedes decision 0003 only for the audio provider and its ElevenLabs permission gate.

The owner selected Stability AI instead of ElevenLabs and requires intelligible sung vocals in the finished songs. The worker uses Stable Audio 3 through the asynchronous text-to-audio API: it starts a generation, records the returned ID, polls the result, validates the MP3, and stores it by content hash. Provider keys stay server-side. The generation ID is persisted before polling so a restart can resume without paying for another start call. An uncertain start outcome is held for reconciliation.

Stable Audio 3 produces instrumental music, according to [Stability's prompt guide](https://stability.ai/guides/stable-audio-3-prompt-guide). Its [commercial licensing guide](https://kb.stability.ai/knowledge-base/stable-audio-commerical-and-usage-licensing) describes commercial distribution subject to the applicable terms and acceptable-use policy. A separate vocal-capable provider and a final reviewed song asset are therefore required. The instrumental may be retained as a private draft, but it cannot satisfy the Phase 03 song or publication gate by itself. Every generated component and final recording needs a recorded rights basis, provenance and review.

The [Soundverse Enterprise API vocal-layer workflow](https://platform.soundverse.ai/docs/vocal-layer) is a technical candidate because it accepts an uploaded backing track and exact lyrics, then renders a combined song. Its documented [Distribution license tier](https://platform.soundverse.ai/docs) and idempotency key need account-level confirmation for this catalogue's paid playback and downloads. Google Cloud [Lyria 3 Pro](https://cloud.google.com/blog/products/ai-machine-learning/lyria-3-and-lyria-3-pro-on-vertex-ai) supports user-provided sung lyrics but generates a complete composition, so it does not directly preserve the Stability backing track. No vocal provider is selected or integrated yet.

The owner subsequently requested a free service. [ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) is the leading free, automatable candidate: its [model card](https://huggingface.co/ACE-Step/Ace-Step1.5) lists an MIT license and commercial use, and its local [REST API](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/API.md) accepts lyrics and generates a full sung song. This machine reports 2 GiB GPU memory and 16 GiB RAM; the project documents CPU execution and heavy CPU offload for low-VRAM devices, but no local inference has been run. ACE-Step's hosted browser tool is free but does not supply the unattended API needed for autonomous agents. The owner is deciding whether ACE-Step should replace Stability for all music or only provide vocals. Stability's [API pricing](https://platform.stability.ai/pricing) is credit-based, so keeping its hosted instrumental path does not meet a durable zero-cost requirement.

The earlier ElevenLabs HTTP 402 attempt and permission attestation remain historical evidence only. No ElevenLabs call is part of the selected path. Live Stability generation needs `STABILITY_API_KEY`; no key or generated audio was available at the time of this decision.

Sources: [Stability text-to-audio API](https://docs.stability.ai/api-reference/stable-audio/text-to-audio), [audio result API](https://docs.stability.ai/api-reference/audio-results/fetch-audio-result), [prompt guide](https://stability.ai/guides/stable-audio-3-prompt-guide), [commercial licensing guide](https://kb.stability.ai/knowledge-base/stable-audio-commerical-and-usage-licensing).
