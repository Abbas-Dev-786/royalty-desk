The contract fixes each recipient to an accepted agent account, caps a payout request at 0.1 NEAR, moves owed to pending before transfer, and uses a private callback. Allocation is admin-only. Human-review mode requires the admin to request payouts; autonomous mode permits a recipient to request their own earned payout. The admin cannot choose the amount. An unknown callback remains locked pending; this is safe from duplicate payment but needs an explicit recovery procedure before this phase can be marked verified.
