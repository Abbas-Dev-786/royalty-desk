Depends on: 00–09. Status: not_started. Outcome: a reproducible, honestly evidenced testnet studio release and owner walkthrough.

## Tasks

- **V2-10-01 Fresh environment:** clean install from lockfiles, configure placeholder-only env, start DB/media/worker/web, deploy or verify exact studio WASM hash on testnet, and run `npm run verify:studio`. Record setup time and failures.
- **V2-10-02 Live proof:** with real provider credentials and licensed output, record two attributable NEAR AI agent contributions, two generated playable songs, album publication, human-review run and separate autonomous run. No fixture may be shown as live.
- **V2-10-03 Economic proof:** use listener wallets for finalized song/album purchases and tips; show work-version binding, fee/album allocation, agent entitlements, final child payout receipts and exact conservation. Test one rejection and one recovery path live where safe.
- **V2-10-04 Owner guide:** publish a plain-language platform overview and complete manual browser verification guide for administrator and listener, with expected results, test accounts, wallet prompts and evidence worksheet. Screenshots/video must match the tested revision.
- **V2-10-05 Handoff:** update README/current scope, deployment/recovery/runbook, known limitations, license reference and phase evidence index. Confirm no secrets/private audio or fabricated passes are committed. Prepare hackathon demo/submission material separately; submission needs explicit authorization.

## Evidence and exit

**REL-01** fresh setup and all offline gates pass; **REL-02** actual live model/audio/provider identifiers and playable files recorded; **REL-03** both approval modes observed in browser; **REL-04** final testnet purchase/tip/payout receipts and independent accounting match; **REL-05** owner follows the manual guide successfully; **REL-06** rights/keys/recovery/known gaps are documented. `verified` requires all six. A missing license, live credential, wallet observation or final child receipt is a blocker, never a deferred success.
